# Goqoo-on-kintone Tap

## How do I install these formulae?

`brew install goqoo-on-kintone/tap/<formula>`

Or `brew tap goqoo-on-kintone/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "goqoo-on-kintone/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
